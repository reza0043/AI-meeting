# آزمون‌های استخراج OHLC از تصویر

سه اسکریپت Node، بدون سرور و بدون شبکه. به یک اسکرین‌شات چارت نیاز دارند (همان تصویری
که موتور با آن اعتبارسنجی شده، `2712×1220`); مسیرش را با متغیر محیطی بدهید:

```bash
npm i @napi-rs/canvas jsdom          # فقط برای اجرای این آزمون‌ها
export OHLC_IMG=/path/to/chart-screenshot.jpg
node tests/ohlc-image/fixtures.mjs   # .fixtures/img.rgba + templates.json
node tests/ohlc-image/parity.test.js
node tests/ohlc-image/ui.test.js
node tests/ohlc-image/ui-trim.test.js
```

| فایل | چه چیزی را می‌سنجد |
|---|---|
| `fixtures.mjs` | تصویر را با بوم واقعی (Skia) به خام RGBA و قالب‌های رقمی تبدیل می‌کند |
| `parity.test.js` | خط لولهٔ مرورگر (`canvasTemplates` + `extract`) روی همان تصویری که با NumPy بازبینی شده: اختلاف سطوح OHLC، جهت‌ها، تاریخ‌ها، معادلهٔ کالیبراسیون، آزمون مستقل برچسب قیمت و دودِ رندر |
| `ui.test.js` | مودال و دکمه‌های عملیات در jsdom، و اینکه کلید «ورود تصویر چارت» در نوار پخش (`#btn-import-image`، با `input` جداشده‌ای که هیچ‌گاه به DOM نمی‌رسد) ابزار را اجرا می‌کند، انتخاب از هر کنترل دیگری بی‌واکنش می‌ماند، و اگر کلید نبود پشتیبان کار می‌کند — در حالی که هیچ عنصری به کارت برنامه اضافه نمی‌شود: استخراج، جدول، CSV، نوشتن در `market_datasets`، افزودن به دیتاست‌های انتخاب‌شده، صف‌شدن الگو در `chartdna_saved_patterns`، و کلیک خودکار «جستجو» بعد از ریلود |
| `ui-trim.test.js` | ماکتِ صفحهٔ برنامه برای `chart-dna-ui-trim.js`: کارت قدیمی حذف شود، پنل «رسم چارت و سطوح تحلیل الگو» مخفی شود و همسایه‌ها نه، جاروی داده فقط مالِ ما را پاک کند (دیتاست/الگو/قیمت مرجع/کلیدها)، یک‌بار اجرا شود و با `chartdna_ui_trim='0'` خاموش شود؛ در پایان هم بررسی می‌کند که `chart-ohlc-autopilot.js` دیگر در `index.html`/`sw.js` نیست |

آستانه‌های `parity.test.js` عامدانه باز هستند: هر سطح باید تا ۱ پیکسل (روی نمونهٔ
آزمون ≈۰٫۶۱ دلار) با `reference/xauusd_1h_expected.csv` هم‌خوان باشد و ۹۹٪ سطوح داخل
همان حد بمانند، چون کوانتیزاسیون پیکسلی سقف فیزیکی دقت این خروجی است. اگر بعد از یک
ویرایش بیش از ۱٪ سطوح از حد بگذرد، تغییر رفتاری است و باید بازبینی شود.

`reference/` خروجیِ بازبینی‌شدهٔ دستی (CSV + گزارش) است و اسکرین‌شات در مخزن نیست؛
به همین دلیل آزمون‌ها بدون `OHLC_IMG` با پیغام واضح skip می‌شوند.
